# Nightly OpenAPI & Schemas

The nightly OpenAPI specification is generated automatically from the latest `master` branch of
Agama.

## Stable URLs

### OpenAPI Specifications

- **Modular (JSON)**: `https://agama-project.github.io/openapi/nightly/openapi.json`
- **Modular (YAML)**: `https://agama-project.github.io/openapi/nightly/openapi.yaml`
- **Full / Monolithic (JSON)**: `https://agama-project.github.io/openapi/nightly/openapi_full.json`
- **Full / Monolithic (YAML)**: `https://agama-project.github.io/openapi/nightly/openapi_full.yaml`

### Standalone JSON Schemas

- **Autoinstallation Profile Schema**:
  `https://agama-project.github.io/openapi/nightly/schemas/config.schema.json`
- **Proposal Schema**:
  `https://agama-project.github.io/openapi/nightly/schemas/proposal.schema.json`
- **System Info Schema**:
  `https://agama-project.github.io/openapi/nightly/schemas/system.schema.json`

## Interactive Viewers

You can load these URLs directly into any standard OpenAPI tool:
