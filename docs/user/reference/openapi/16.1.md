# Version 16.1 OpenAPI Specification

The 16.1 OpenAPI specification describes the HTTP API of the Agama installer corresponding to the
`SLE-16.1` release branch.

## Stable URLs

- **JSON Format**: `https://agama-project.github.io/openapi/16.1/openapi.json`
- **YAML Format**: `https://agama-project.github.io/openapi/16.1/openapi.yaml`

## Interactive Viewers

You can load these URLs directly into any standard OpenAPI tool:

- [Open in Swagger Editor](https://editor.swagger.io/?url=https://agama-project.github.io/openapi/16.1/openapi.json)
- View locally with `openapi-spec-validator`:
  ```sh
  openapi-spec-validator https://agama-project.github.io/openapi/16.1/openapi.json
  ```
